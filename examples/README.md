# Examples

This directory contains short, sanitized examples for public documentation.

The files here are illustrative only. They are not full evaluation outputs and do not contain private corpus text, local database files, model responses, or machine-specific paths.

## Layout

```text
examples/
  configs/      notes for example configuration templates
  docs/         placeholder notes for future public walkthroughs
  eval/         sample answer-eval and review artifacts
  mini_corpus/  placeholder for a future synthetic mini corpus
```

## How to Read These Files

- `.sample.json`, `.sample.jsonl`, and `.sample.csv` files show record shapes.
- `.sample.md` files show report structure.
- Values are shortened and sanitized.
- These files are not evidence of broad evaluation quality.
- They are meant to help readers understand the workflow without exposing private local artifacts.

## Not Included

This directory does not include raw documents, generated vector stores, generated SQLite indexes, full logs, long model outputs, or private corpus excerpts.
