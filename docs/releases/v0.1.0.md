# v0.1.0 Release Draft

## Summary

v0.1.0 is the first safe public release draft of Domain-RAG-Agent-with-enhanced_sql_relation. It packages a local-first Domain-RAG Agent prototype with controlled SQL-relation retrieval, evidence quality checks, answer reliability records, and a human-review workflow.

No GitHub release or tag has been created yet.

## Highlights

- `enhanced_sql_relation` controlled retrieval fusion.
- Local-first project structure.
- Relation-path explainability.
- Failure triage and adjudication workflow.
- Streamlit inspection UI.
- Controlled LangGraph workflow skeleton.
- Synthetic public mini demo.

## Public Mini Demo

```powershell
conda run -n Lenginzed_RAG python scripts/build_mini_demo_index_v51.py
conda run -n Lenginzed_RAG python scripts/run_mini_demo_v51.py
conda run -n Lenginzed_RAG python -m pytest tests/test_v51_public_mini_demo.py tests/test_v52_public_docs_links.py
```

## What is included

- Source code for loaders, retrieval, SQL relation utilities, generation helpers, evaluation helpers, UI services, and controlled workflow traces.
- Example configuration templates.

## What is not included

- Model weights.

## How to try it

Start with the public mini demo:

1. Install dependencies.
2. Build the temporary mini relation index.
3. Run the mini demo.
4. Run the lightweight checks.

See [public walkthrough](../public_walkthrough.md).

## Safety and data boundary

The public repository is intentionally code-first and example-only. It excludes private local data and generated runtime artifacts. Users must build their own local indexes for full workflows.

## Known limitations

- Not intended for production use.
- No private corpus included.
- No prebuilt Chroma or SQLite indexes.
- Mini demo is synthetic and retrieval-only.
- Full workflows require local data and generated artifacts.
- Evaluation claims are limited to local examples.
